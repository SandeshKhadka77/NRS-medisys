# 🏥 NRS-Medisys — Hospital Management System (Frontend)

NRS-Medisys is a **frontend-based Hospital Management System project** built as part of my learning journey in **web development**.  
This project focuses on designing a clean, user-friendly hospital interface using **HTML, CSS, and JavaScript**.

---

## 📌 Project Overview

NRS-Medisys is designed to represent how a basic hospital management system looks and behaves on the frontend.  
It includes essential hospital-related sections such as patient services, doctor information, appointments, and general hospital details.

This project is **frontend-only** and does not include backend or database functionality.

---

## 🛠️ Technologies Used

- **HTML5** — Structure of the website  
- **CSS3** — Styling, layout, and responsiveness  
- **Tailwind CSS** - 
- **JavaScript (Vanilla JS)** — Basic interactivity and UI behavior
